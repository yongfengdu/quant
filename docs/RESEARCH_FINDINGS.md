## 一、涨停（limit-up）信号调研

### 背景与动机
涨停板是 A 股独有的制度性信号，代表"极端的资金关注"。假设它可作为信号或辅助过滤。用户直觉：涨停波动大，不宜直接交易，但可辅助其他信号。

### 调研发现

**1. 涨停股整体是负期望 + 高方差（不宜直接交易）**

| 指标 | 涨停股 | 普通股 |
|------|--------|--------|
| 上涨率 | 42.6% | 47.5% |
| 3%命中率 | 25.6% | 11.1% |
| 均收益 | -0.43% | +0.04% |
| 抖动 std | 7.12% | 3.18% |
| 亏>10%占比 | 7.3% | 0.4% |

**2. 涨停股内部极度分化（关键）**

| 类型 | 占比 | 上涨率 | 均收益 |
|------|------|--------|--------|
| 连板（次日继续涨停） | 22% | 86.2% | +7.59% |
| 首板（次日炸板） | 78% | 30.7% | -2.62% |

涨停股整体负期望，因为 78% 首板亏钱、22% 连板暴赚 → "高方差彩票"。

**3. 涨停作为辅助过滤：仅对反转有效、对动量有害**

| 组合 | 3%命中率 | 均收益 |
|------|---------|--------|
| 反转底部档（无过滤） | 11.0% | +0.07% |
| 反转底部档 ∩ 近期涨停 | 23.0% | +0.40% ✅ |
| 动量顶部档（无过滤） | 10.1% | -0.01% |
| 动量顶部档 ∩ 近期涨停 | 24.0% | -0.48% ❌ |

- 超跌 + 涨停 = "跌惨了但有人买"，有效
- 追高 + 涨停 = "追涨陷阱"，有害

**4. 时间窗口扫描**：窗口越短效果越强（N=1 命中率 26.2%，N=10 降到 17.6%），说明是涨停的"即时溢价"效应，衰减很快。

**5. 时间尺度错配（重要教训）**
- 涨停 = 快信号（1 日尺度）
- 反转 = 慢信号（20 日尺度）
- 把涨停过滤加在 20 日反转组合上**无效**（Sharpe 0.84 → 0.78）

### 涨停 vs 20日反转 收益/稳定性对比

| 策略 | 年化收益 | Sharpe | 回撤 | 胜率 |
|------|---------|--------|------|------|
| 20日反转（regime门控） | +19.8% | 0.84 | -29.1% | 55% |
| 涨停打板（买所有涨停次日卖） | -66.2% | -1.17 | -100% | 42% |
| 超跌+近1日涨停（短线） | +175%* | 1.55 | — | 47% |

*短线策略 +175% 是按交易日年化的假象：8.5 年仅 266 次触发，单笔 +0.65%，极稀疏。

### 结论
1. 涨停是"高方差彩票型"信号，**单独交易是灾难**（年化 -66%）
2. 作为短线过滤（超跌+涨停）虽有 26% 命中率，但**太稀疏**（0.13 次/天）无法构成组合
3. 涨停的价值在别处：**情绪温度计 / 事件标记**（如检测集中涨停潮来辅助判断反转信号出手时机），而非直接收益来源

## 二、核心认知沉淀（跨调研）

1. **信号来源** = 可预测的集体行为偏差（情绪/共识/认知偏差），统计只是测量工具
2. **信号 → 盈利链**：偏差存在 → 可编码 → 可预测 → 可下注 → 回归兑现。代码可捕捉是必要非充分条件
3. **信号会衰减**（零和 + 机构化），需持续发现新信号 + 监控衰减
4. **时间尺度要匹配**：快信号（事件/涨停）和慢信号（反转/动量）不可混用
5. **分档端超额 ≠ IC**：长头寸组合要看"买入档实际超额"，不能只看全截面 IC

## 四、涨停温度计调研（2026-09-06）

### 背景
假设涨停/炸板数量可作为市场情绪温度计，给反转信号择时。

### 发现
1. **涨停数量温度计价值有限**（推翻初始假设）
   - 涨停多→反转强（+0.86%），涨停少→反转弱（+0.17%）
   - 本质是"波动率代理"，与 regime 检测重叠，无增量价值
   - lu_ratio 与 mkt_ret_20d 相关仅 +0.21

2. **炸板率温度计有真实价值**
   - 炸板数 0只 +0.25% / 1-3只 +0.60% / 4-10只 +0.83% / >10只 -1.66%
   - 适度炸板增强反转，极端炸板潮(>10只)是崩盘危险信号
   - 有领先性：T-1 高炸板率 → T 反转超额 +0.61% vs 低 +0.24%
   - **独立于 regime**：bear 内增量 +0.72pp、range +0.48pp、bull +0.04pp(无)

### 结论
炸板率 = 反转信号的"增强开关 + 危险警报"：
- 熊/震荡市里高炸板率（追涨失败=情绪见顶）→ 加大反转仓位
- 极端炸板潮 → 回避反转（崩盘风险）
- 因果解释：炸板 = 游资/散户追涨失败 = 情绪见顶回落 = 反转开始

### 待后续验证
- [ ] 把炸板率作为反转信号的增强权重，集成进 regime 门控组合，验证能否提升 Sharpe
- [ ] 极端炸板潮(>10只)的避险规则验证（样本仅4天，需更多数据）

## 五、炸板率集成验证（2026-09-06）

### 结果
炸板率集成进 regime 门控组合（月度调仓）：
- 危险回避（炸板>10空仓）：无效——极端炸板潮8.5年仅4天，不在月度采样点
- 增强（仅1-10炸板做反转）：回撤-29%→-14.6%（减半），但超额+11.2%→+5.2%（也减半），Sharpe 0.84→0.82 基本不变

### 教训（重要）
**信号时间尺度必须与交易频率匹配**。炸板率是日度信号，月度调仓时"空仓44%时间"错过的反转收益，抵消了其单日增量（bear +0.72pp）。单日统计显著 ≠ 组合层面增量。

### 结论
炸板率月度集成价值有限，需日度调仓才能发挥（但换手成本高）。此线调研收敛，回到主线。

## 六、LLM 发现的行为因子验证（2026-09-10）

### 结果
3 个 LLM 因子（彩票偏好/非流动性/量价背离）：
- IC +6~8%，与 dist_ma60/dist_hi20 相关性仅 -0.2~-0.3（正交）
- 非流动性+MAX 独立超额 +6.84%、Sharpe 0.78 最强
- 但 LLM_1984 与 LLM_2253 相关性 0.75（互相重复）

### 朴素纳入组合结果
- baseline regime门控: Sharpe 0.84
- +3个LLM因子等权: Sharpe 0.70（变差）

### 结论
1. LLM 能找到真实、正交的信号（验证自进化价值）
2. 但朴素等权组合会稀释强信号（LLM因子独立Sharpe 0.59-0.78 < 门控0.84）
3. 正确用法是"分仓"（LLM因子作低相关卫星仓位），需风险平价/均值方差等组合构建，非当前简单等权

- [ ] 去重：LLM_1984 与 2253 相关性0.75，只保留其一

## 七、组合分仓验证（2026-09-10）

### 结果
主仓(regime门控) + 卫星仓(LLM非流动性因子) 分仓组合：
- 主仓100%: Sharpe 0.841, 回撤 -29.1%
- 主仓80%/卫星20%: Sharpe 0.849, 回撤 -27.5% (最优)
- 风险平价(46%/54%): Sharpe 0.841, 回撤 -25.4%

### 关键发现
两仓收益相关性 0.852（远高于因子层面 -0.28），因为都是多头、共享市场 beta。

### 结论
1. 分仓是正确方向（对比朴素混合 0.70），但改善有限（Sharpe +1%）
2. 根本约束：A股做不了空，多头信号共享 beta，分散化天花板被锁死
3. 真正分散化需要市场中性/跨资产/跨周期，A股多头框架下达不到

### 最优配置
主仓 80% + 卫星 20%，Sharpe 0.849
