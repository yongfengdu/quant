## 分析要点（不要逐项回答，融会贯通）

**交易数量与信号质量的匹配度：**
- 1000+ 笔但均收益为负 → 大部分是噪声，条件太松
- <50 笔且准确率低 → 条件太严，随机性主导
- <50 笔但准确率高 → 可能是过拟合，需要更多样本验证
- 判断信号集中在少数股票还是均匀分布

**盈亏结构：**
- 盈利单的幅度分布 vs 亏损单的幅度分布
- 是"小盈大亏"还是"大盈小亏"？
- 是否有极端亏损单拖累整体

### 系统改进 (JSON)

```json
{
  "banned_update": null,
  "config_update": null
}
```

- banned_update: 封存已穷举的无效方向。要求: (1) 同一方向累计 ≥5 次独立实验且全部失败; (2) 不是单调改进趋势（如果准确率或回撤在逐轮改善,说明方向在收敛而非饱和,不应封存）; (3) 已充分尝试不同粒度（至少涵盖宽/中/严三种参数设置或不同切入角度）。不确定时设为 null。
- config_update: 成功标准需调整时提出
